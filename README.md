# קטלוג ספרים — גרסה 3 (גנרית)

תוכנת קטלוג לספרייה: פייתון + SQLite, קובץ אחד (`book_catalog.py`), בלי שם, מיקומים או נתונים מוגדרים מראש.

## הקבצים
| קובץ | תוכן |
|---|---|
| `book_catalog.py` | התוכנה הגנרית |
| `builder.html` | דף אינטרנט שמקבל את פרטי הספרייה (בטופס או בקישור) ומוריד את התוכנה המותאמת |
| `AGENT.md` | הנחיות ל-agent: מה לשאול, מבנה הפרופיל, ומבנה הקישור |
| `profiles/` | פרופילים ונתונים של ספריות ספציפיות (לא חלק מהגרסה הגנרית) |

## הפעלה
```
pip install pywebview        (מומלץ - חלון עצמאי; בלי זה התוכנה נפתחת בדפדפן)
python book_catalog.py
```
בהפעלה ראשונה בלי פרופיל נפתח אשף: שם הספרייה, עיצוב, מיקומים וסיסמת מנהל.

- בדיקה עצמית: `python book_catalog.py --selftest`
- איפוס סיסמת מנהל: `python book_catalog.py --reset-password`
- הטמעת פרופיל: `python book_catalog.py --embed profile.json my_catalog.py`

## האתר
מעלים את `builder.html` ואת `book_catalog.py` לאותה תיקייה בכל אחסון סטטי. הדף בונה את הקובץ בדפדפן; שום פרט לא נשלח לשרת.

## יכולות
- חיפוש בסגנון מנוע חיפוש, סוגי חיפוש שהמנהל מגדיר, חיפוש מתקדם, ארבע תצוגות תוצאות.
- נספחים: נספח שנמצא בחיפוש מוצג בתוך הספר הראשי שלו; תווית לכל ספר.
- מיקום אוטומטי לפי מספר המדף (טווחים ואותיות).
- מצב מנהל בסיסמה: טקסטים, עיצוב, סמל ICO, לוגו, מסך פתיחה, שדות, מיקומים, מצבים, רשימות ערכים, הרשאות.
- ייבוא וייצוא Excel / CSV, גיבוי ושחזור, עדכון גרסה מתוך התוכנה (הפרופיל נשמר בעדכון).
