# קטלוג אוצר הספרים — גרסה 3.0

תוכנת קטלוג בפייתון + SQLite, קובץ אחד: `book_catalog.py`.

## הפעלה
```
pip install pywebview        (מומלץ - חלון עצמאי; בלי זה התוכנה נפתחת בדפדפן)
python book_catalog.py
```
בדיקה עצמית: `python book_catalog.py --selftest` · איפוס סיסמת מנהל: `python book_catalog.py --reset-password`

## התקנה ראשונה של הנתונים
1. כפתור המנעול 🔒 > קביעת סיסמת מנהל.
2. ⚙ הגדרות > נתונים > ייבוא מקובץ > `ייבוא_לתוכנה.xlsx` (או ה-CSV) > **החלפת כל הקטלוג**.

## הקבצים
| קובץ | תוכן |
|---|---|
| `book_catalog.py` | התוכנה |
| `ייבוא_לתוכנה.csv` / `.xlsx` | הקטלוג המעודכן: 19,457 ספרים, כולל עמודות **תווית**, **נספח לספר**, כרך הספר הראשי, ומספרי קישור |
| `נספחים_ללא_ספר_ראשי.csv` | 47 נספחים שלא נמצא להם ספר ראשי חד-משמעי בקטלוג (נשמרו עם שם הספר הראשי כטקסט) |

## מה חדש בגרסה 3
- **נספחים**: חיפוש נספח מציג את הספר הראשי, והנספח מסומן בתוכו. תווית מוצגת ליד כל ספר.
- **מיקום לפי מדף**: 1–399 אויצר, 400–700 עזרת נשים, 900–999 ארכיון, מדף עם האות פ = פרוזדור (ניתן לשינוי).
- **סוגי חיפוש** בכניסה (הכל / שם / מחבר / נושא / תוכן / נספחים / הוצאה / מדף) — המנהל מגדיר אותם.
- **מצב מנהל בסיסמה**: טקסטים, עיצוב וצבעים, גופנים, סמל ICO, לוגו, מסך פתיחה, סוגי חיפוש, שדות, מיקומים, מצבים, רשימות ערכים, הרשאות למי שאינו מנהל.
- **תצוגות תוצאות**: כרטיסים / רשימה / טבלה / אריחים.
- **ייצוא** ל-Excel (xlsx אמיתי) ול-CSV, עם בחירת עמודות והיקף; **ייבוא** מ-Excel ומ-CSV (הוספה / עדכון / החלפה).
- **עדכון גרסה**: הגדרות > עדכון גרסה > בחירת קובץ הגרסה החדשה — התוכנה מחליפה את עצמה ונפתחת מחדש.
