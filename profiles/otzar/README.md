# אוצר הספרים

- `profile.json` — פרטי הספרייה (שם, מיקומים, מצבים).
- `ייבוא_לתוכנה.csv` / `.xlsx` — הקטלוג: 19,457 ספרים, כולל תווית ונספחים.
- `נספחים_ללא_ספר_ראשי.csv` — 47 נספחים שלא נמצא להם ספר ראשי חד-משמעי.
- `screens/` — צילומי מסך.

בניית התוכנה של הספרייה: `python book_catalog.py --embed profiles/otzar/profile.json otzar_catalog.py`
