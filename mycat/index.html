הכנת תוכנת קטלוג מותאמת

ממלאים את פרטי הספרייה (או מקבלים קישור שבו הפרטים כבר מלאים), ולוחצים על ההורדה. מתקבל קובץ תוכנה אחד שכבר מכיר את שם הספרייה, המיקומים והעיצוב. שום פרט לא נשלח לשרת: הקובץ נבנה כאן, בדפדפן.

פרטי הספרייה

מיקומים ומדפים

המיקום של כל ספר נקבע לפי מספר המדף (1–999). לכל מיקום: טווח מדפים, או אות שנכתבת ליד מספר המדף. אפשר להשאיר ריק ולהגדיר אחר כך בתוכנה.

אחרי ההורדה

  1. מתקינים פייתון (3.8 ומעלה). מומלץ גם: pip install pywebview — כך התוכנה נפתחת בחלון משלה ולא בדפדפן.
  2. מפעילים: python book_catalog.py
  3. לוחצים על המנעול וקובעים סיסמת מנהל. משם אפשר להוסיף ספרים, לייבא קטלוג קיים (Excel או CSV), ולמחוק ספרים מהקטלוג הבסיסי.
